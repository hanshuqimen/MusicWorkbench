# 本机验证记录

测试日期：2026-10-01。Windows、RTX 5060 Laptop GPU（8 GB）、CUDA 12.8、PyTorch/torchaudio 2.7.1，Python 3.11.15。此记录区分真实执行与待验收项目。

## 已执行

- TypeScript strict 类型检查、Vite 生产构建、Python 编译检查。
- 后端工程容器、安全路径、会话鉴权、数据校验、MIDI 秒／tick 变速与延音、四预设确定性及主旋律锚点保留测试。
- 真正的 CUDA 张量运算和六轨模型推理；Basic Pitch 显式 ONNX 适配器，无完整 TensorFlow。
- SpessaSynth SF2 生成 8 秒参考四轨混音，再执行 Demucs 六轨分离、钢琴／吉他／贝斯 ONNX 转谱、鼓起点与频带类别分析，以及四预设风格生成。报告见 `output/integration-report.json`。
- 总流程 35.37 秒，GPU 分离 11.531 秒，显存峰值 621.56 MiB。相对参考分轨的简单 SNR：鼓 8.93 dB、贝斯 10.74 dB、钢琴 8.13 dB、吉他约 0 dB。此结果只代表短合成素材，不代表真实歌曲质量。
- 分离／转谱缓存二次命中，四种编配产生不同事件，未选中的人声／其他音轨内容保持不变。
- 实际 Electron 页面操作：四拍倒数后 A+D 同时演奏，记录为两个音符；页面无控制台错误。截图位于 `output/playwright`。
- 18 项后端测试、2 项前端采样器／混音选择测试通过。真实解码 WAV、MP3、FLAC、M4A；中文路径、22.05 kHz 单声道统一为 44.1 kHz 立体声；损坏音频、500 MB 超限、10 分钟超限均拒绝。
- 独立打包程序在测试 PATH 不含 Node/Python 的环境下自动启动后端、录制与延音、工程保存重开、MIDI/WAV/MP3 导出及真实 CPU 六轨分离通过。8 秒 CPU 分离约 29.14 秒。测试对话框仅选择固定本机输出路径，处理与合成均为实际程序执行。
- 导出 WAV 和解码后的 MP3 均为 44.1 kHz、17.5 秒，峰值约 0.1533（低于满幅），非静音。数据见 `output/desktop-qa/audio-metrics.json`。
- 10 分钟、48 kHz、中文文件名的实际输入（115 MB）成功统一采样率并分离成六轨。GPU 分离 49.447 秒，显存峰值 621.56 MiB，总耗时 73.13 秒。素材由参考混音循环组成，覆盖文件时长与内存处理，不覆盖长曲音乐质量。见 `output/stress-report.json`。
- 真实任务队列取消后重试、四轨兼容模型分离通过。显式注入 OOM 故障后，实际模型缩短到 3 秒分段继续 GPU 推理；再次故障时真实 CPU 分离完成。此项为故障注入测试，非本机真实显存耗尽。见 `output/acceptance-report.json`。
- 实际桌面界面执行完整导入、六轨分离、预览试听、四预设单轨改编、多轨改编和钢琴卷帘新增／撤销／重做／量化；主旋律音高与起点保留、未选轨不变、四种结果有区别。后台推理期间双键演奏保持操作，尚未测量声卡输出的真实延迟。见 `output/workflow-qa/report.json`。
- 使用独立 Python 与 CPU 基础包，再覆盖已从官方安装并验证的 GPU 包，实际六轨 GPU 推理通过。此项验证运行环境兼容性，未模拟从零完整下载 3.28 GB GPU wheel。见 `output/isolated-gpu-report.json`。
- Windows 按用户安装包在本机静默安装退出码 0，随后可卸载。安装验证位于项目专用目录；不是独立全新 Windows 机器验证。
- 打包进 Microsoft 官方签名可再分发包中提取的 AMD64 C++ 运行库，保留 SHA-256、固定下载地址及完整软件许可。启动的推理自检实际执行短 Demucs 模型前向。
- 安装版本实际加载应用目录内 `msvcp140.dll`，未依赖外部开发运行环境路径；退出后所属后台进程数为 0。见 `output/desktop-qa-packaged/runtime-report.json`。
- 真实乐器验证：单弦拨动后自动释放、六弦跨弦拖动录成独立音符、四弦贝斯双键、鼓垫双键录制通过。倒数后的音符按实际播放时钟记录。见 `output/instruments-qa/report.json`。
- 后台分离时，用只读分析器检测到主输出节点有真实采样音频，界面双键输入正常。此测试不测量声卡硬件输出延迟。
- 独立打包程序使用全新用户目录与关闭的本机 HTTP/HTTPS 代理，实际验证资源下载失败后仍可演奏、校验离线资源 ZIP 导入、真实 CPU 模型自检、后端一键重启、日志导出及离线重开自动启动。此项阻断资源网络请求，未代替独立机器物理断网验证。见 `output/offline-qa/report.json`。
