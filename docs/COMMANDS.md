# 指令演奏速查

| 写法 | 含义 |
|---|---|
| `ASDFDGS` | 按顺序演奏七个按键 |
| `a s d f` | 等同于 `ASDF`，大小写与空白不影响演奏 |
| `A-S` 或 `A.S` | A、一个位置的停顿、S |
| `[AD]F` | 同时弹奏 A+D，然后演奏 F |
| `[AD]-[SG]` | 和弦、停顿、和弦 |

每个位置按速度与时值转换为真实秒数：`60 / BPM × 4 / 分母`。120 BPM、八分音符下，每个位置 0.25 秒；发声音符时长为该位置的 85%，为相邻音符保留间隙。最多 4000 个字符、2000 个位置、10 分钟。

- 屏幕键盘：A W S E D F T G Y H U J K O L P ;，默认 C4 至 E5。
- 吉他：A S D F G H，对应六根弦，先在指板选择品位。
- 贝斯：A S D F，对应四根弦。
- 鼓：A S D F J K L ;，对应底鼓、军鼓、闭镲、开镲、低嗵、高嗵、吊镲、叮叮镲。

不支持的字符会在输入框下提示，不会静默略过。使用 `[` 和 `]` 包围同时弹奏的按键；不要在括号内放停顿符。指令不会在 Python 后端逐次请求发声，而由本地 AudioWorklet 按音频时钟调度。

有效指令输入后会自动生成当前音轨上的旋律，无需点击写入。首次输入以当前播放光标为起点，修改指令、速度、时值、八度或品位会更新同一段音符，不会重复追加。每条音轨独立保存指令和演奏设置，切换乐器或保存重开后可继续编辑。

无效或未写完的指令保留上一段有效旋律；清空指令只删除它生成的片段，不删除另外弹奏或录制的音符。循环选项只控制指令试听，不会重复录入音符。

自动生成的音轨支持钢琴卷帘、量化、撤销／重做、风格编配，以及工程、MIDI、WAV、MP3 导出。直接演奏在创作模式默认自动记录，可关闭“自动记录演奏”进行练习，也可继续使用倒数录制。
