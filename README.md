# MusicWorkbench

**在本地改编音乐，也从零创作音乐。**

MusicWorkbench 是一款面向 Windows 的音乐改编与创作桌面应用。你可以导入歌曲、分离音轨、选择乐器进行风格编配，也可以通过虚拟乐器或按键指令演奏、录制和编辑自己的作品。音频分析、合成与导出均在本机完成，无需云端 API。

[下载安装](https://github.com/hanshuqimen/MusicWorkbench/releases) · [指令演奏速查](docs/COMMANDS.md) · [反馈问题](https://github.com/hanshuqimen/MusicWorkbench/issues)

> 当前版本为 **0.3.0 测试版**，安装包尚未签名。自动分离和转谱可能存在误差，建议先试听短片段，再生成全曲。

## 功能

- **音轨分离与混音**：导入 WAV、MP3、FLAC、M4A；使用 Demucs 分离音轨，支持独奏、静音、音量、声像及均衡、压缩、失真、合唱、延迟、混响效果。
- **风格改编**：将选中的音轨转为音符，调整配器、节奏、伴奏、力度与装饰音；支持片段预览、主旋律选择和风格强度调整。
- **虚拟乐器**：通过鼠标和电脑键盘弹奏琴键、按品拨弦、扫弦或击打鼓垫，支持八度、力度与延音控制。
- **指令演奏**：输入 `WASD` 或 `ASDFDGS` 自动生成旋律音轨，支持和弦、停顿、速度、循环及风格编配。
- **创作与编辑**：演奏默认自动记录，支持倒数录制、节拍器、多轨编辑、循环播放、钢琴卷帘、主动量化、撤销与重做。切换乐器保留各轨的旋律、风格、指令与演奏设置。
- **保存与导出**：保存可移动的 `.mwork` 工程，导出 MIDI、WAV、MP3 或单独音轨。
- **自动初始化**：应用自动管理本地后端，支持资源下载、校验、离线资源包导入、GPU 检测与 CPU 回退。
- **应用内帮助**：可搜索的使用指引和界面高亮导览。

### 乐器与风格

提供 **16 种可演奏乐器**：钢琴、电钢琴、风琴、吉他、贝斯、鼓、小提琴、大提琴、长笛、萨克斯、小号、手风琴、竖琴、筝、三味线和风笛。

提供 **10 种可编辑风格预设**：

| 风格 | 编配方向 |
| --- | --- |
| 中国古典器乐 | 拨弦、笛类音色、分解伴奏与五声音阶装饰 |
| 日式传统器乐 | 筝、三味线、尺八音色与稀疏短句 |
| 苏格兰民谣 | 风笛、提琴、持续音与舞曲重音 |
| 俄罗斯民谣 | 手风琴、拨弦、轮拨与和弦伴奏 |
| 爵士摇摆 | 七和弦、摇摆节奏与行进低音 |
| 布鲁斯 | Shuffle 节奏与布鲁斯伴奏 |
| 摇滚 | 五度和弦与八分音符脉冲 |
| 波萨诺瓦 | 切分伴奏与根音／五度低音 |
| 圆舞器乐 | 三拍重音感与和弦伴奏 |
| 氛围器乐 | 长音与稀疏织体 |

预设表达器乐编配方向，保留主旋律，不强制将旋律改成某种音阶，也不会自动改变整曲速度或拍号。默认音源为 GeneralUser GS；部分民族乐器使用近似音色，界面显示实际音源。可导入 SF2 扩展音源。

## 下载与安装

### 系统要求

- Windows x64；当前仅提供 Windows 安装包。
- 建议至少 **16 GB 内存**，为安装、资源下载与解压预留 **15 GB 磁盘空间**。长音频及多轨导出需要更多内存和存储空间。
- CPU 可运行全部音频处理功能；兼容的 NVIDIA GPU 可加速分离。GPU 扩展使用 CUDA 12.8，应用会检测可用设备，失败时回退到 CPU。
- 首次下载资源需要联网；资源准备完成后可离线使用。

### 安装步骤

1. 打开 [Releases](https://github.com/hanshuqimen/MusicWorkbench/releases)，下载 `MusicWorkbench Setup 0.3.0.exe`。
2. 运行安装程序，按提示完成当前用户安装，然后打开 MusicWorkbench。
3. 应用会自动启动后端。默认采样音源已包含在安装包中，首次初始化下载分离与转谱模型，约 **139 MB**。
4. 如需 GPU 加速，按提示下载可选 CUDA 运行组件，约 **3.28 GB**。取消该下载后仍可使用 CPU 处理，并可在设置中重试。

安装版包含所需运行环境和 FFmpeg，**无需自行安装 Node.js 或 Python，也无需手动启动后端**。Release 同时提供 `SHA256SUMS-0.3.0.txt`，可用 PowerShell 的 `Get-FileHash -Algorithm SHA256` 校验下载文件。

### 离线使用

在可联网的设备上，从同一 Release 下载 `MusicWorkbench-resources.zip`，将安装包和资源包复制到目标电脑。安装后打开 **设置 → 导入离线资源包**，选择 ZIP 并等待校验完成。此资源包包含基础模型与音源，CPU 离线使用无需安装 GPU 扩展。

## 开始使用

### 改编已有音乐

1. 导入或拖入音频文件。单文件限制为 **10 分钟、500 MB**。
2. 点击 **分离音轨**，选择六轨模式或四轨兼容模式。
3. 试听分离结果，勾选希望改编的乐器，选择风格、强度及主旋律轨。
4. 先生成片段预览，默认前 20 秒；满意后再生成全曲。
5. 在音符视图中修正转谱结果，调整音高、起点、时长和力度，再设置各轨音量与效果。
6. 保存工程，或从导出菜单导出音频、MIDI 与单独音轨。

六轨模式输出钢琴、吉他、贝斯、鼓、人声与其他；四轨兼容模式输出人声、鼓、贝斯与其他，无法单独选择钢琴和吉他。

生成音轨会替换选中的源音轨，再与未选中的分离音轨混合，保持原时间轴。人声与“其他”支持原声保留、混音及效果处理，当前不自动重新编配。“其他”可能包含多种乐器，轨道类别均为模型估计，可自行改名。

### 自由演奏与录制

进入创作页，选择乐器，按界面提示使用鼠标或电脑键盘演奏。吉他与贝斯先选择品位，再拨动单弦；吉他还支持跨弦拖动扫弦。新增旋律乐器使用屏幕键盘操作。

创作工作台默认开启 **自动记录演奏**：直接弹奏，音符会自动出现在上方音轨，无需先点击录制或手动添加。可以循环重放、在钢琴卷帘编辑音符，以及为当前音轨选择风格。只想练习时可关闭自动记录。

切换乐器会回到该乐器已有的音轨，保留旋律、音色、效果、指令、八度、力度、品位和风格设置。创作模式切换音轨时默认仅选中当前轨进行编配；需要一起改编时，再勾选其他音轨。底部播放栏可以同时重放所有未静音的轨道。

需要跟随其他音轨录制时，可使用四拍倒数录制。演奏和录制默认保留实际时间；需要对齐节拍时，再主动应用量化。

| 乐器界面 | 电脑键盘按键 |
| --- | --- |
| 屏幕键盘 | `A W S E D F T G Y H U J K O L P ;`，默认 C4–E5 |
| 吉他六弦 | `A S D F G H` |
| 贝斯四弦 | `A S D F` |
| 八个鼓垫 | `A S D F J K L ;` |

钢琴可使用 `Shift` 延音。完整操作说明可在应用右上角 **使用指引** 中搜索，也可以启动界面导览。

### 输入指令自动弹奏

在乐器面板输入按键序列，设置 BPM 和四／八／十六分音符时值。有效输入会自动生成当前音轨上的一段旋律，点击“自动弹奏”即可试听。指令使用当前乐器的按键映射；琴弦按当前品位发声，旋律乐器按当前八度发声。

| 指令 | 效果 |
| --- | --- |
| `ASDFDGS` | 依次弹奏七个按键 |
| `a s d f` | 等同于 `ASDF`，忽略大小写与空白 |
| `A-S` 或 `A.S` | A、停顿、S |
| `[AD]F` | 同时弹奏 A 与 D，然后弹奏 F |
| `[AD]-[SG]` | 和弦、停顿、和弦 |

支持 20–300 BPM、循环与停止。首次输入从当前播放光标处生成片段；继续修改指令或时值会更新同一段，不会逐次重复追加，也不会删除另行演奏的音符。清空指令仅移除该指令生成的片段；无效或未写完的指令保留上一段有效旋律。每条音轨独立保存指令，保存重开后也可继续编辑。更多规则见 [指令演奏速查](docs/COMMANDS.md)。

### 保存与导出

- **`.mwork` 工程**：包含原音频、分离结果、音符、编配版本、混音参数及扩展音源，移动文件后仍可重新打开和编辑。
- **MIDI**：包含音符与延音等控制事件，不包含原音频与音频效果；在其他软件中播放时，音色取决于其音源。
- **WAV／MP3**：保存实际混音后的声音，也可导出单独音轨。

## 常见问题

**分离结果出现串音，或音符不准确？**

自动分离与转谱不是无损恢复，钢琴与吉他尤其可能互相串音。先用独奏试听，再选择主旋律轨、编辑音符；必要时恢复当前轨原声。六轨模型并不意味着输入一定包含六种乐器。

**初始化失败或处理较慢？**

在设置中使用“校验／下载资源”“导入离线资源包”或“重新启动后端”。可将计算设备改为“强制 CPU”；CPU 处理耗时取决于音频长度与硬件。仍有问题时，导出诊断日志并提交 Issue。

**数据保存在哪里？**

应用管理的模型、GPU 组件、设置、日志、缓存及自动恢复文件通常位于 `%APPDATA%\music-workbench`。主动保存的 `.mwork` 工程和导出作品位于你选择的目录。

**如何卸载？**

安装版可通过 Windows 应用列表、安装目录卸载器或 **设置 → 完全卸载应用** 卸载。卸载会关闭所属进程并清除应用管理的运行环境、依赖、模型、音源、GPU 组件、缓存、日志、设置与自动恢复工程，同时移除安装文件、快捷方式和注册信息。**卸载前请将需要保留的作品另存为工程文件。** 更新安装会保留用户数据。

便携构建可从设置启动便携清理。另存的工程、导出作品、下载的安装包及源码目录需要自行管理。

## 当前限制

- 尚不支持外接 MIDI、VST 宿主、云端服务、触屏适配及五线谱／简谱／六线谱导出。
- 扩展 SF2 当前使用 Bank 0；近似民族音色不替代专业采样库。
- 测试版仍需更多独立 Windows 环境、长曲及真实歌曲验证；演奏响应、推理速度与导出内存占用会随硬件和项目规模变化。

## 源码开发

### 初始化与启动

在 Windows PowerShell 中执行以下命令。克隆仓库需要 Git；初始化脚本会准备所需的 Node.js、pnpm、uv、Python 3.11、依赖、FFmpeg、模型和音源，首次运行需要网络及足够磁盘空间。

```powershell
git clone https://github.com/hanshuqimen/MusicWorkbench.git
cd MusicWorkbench

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\setup.ps1 -Cpu
node scripts/dev.mjs
```

`-Cpu` 使用 CPU 版 PyTorch。需要 CUDA 12.8 开发环境时，初始化命令改为 `.\setup.ps1`。脚本会将下载的 Node.js 加入当前 PowerShell 会话的 PATH；开发命令在同一会话执行。

初始化后也可双击 `launch.cmd` 启动应用；若已生成独立构建，该启动器优先打开 `release/win-unpacked/MusicWorkbench.exe`。

### 检查与构建

在已完成初始化的 PowerShell 会话、仓库根目录中执行：

```powershell
# 前端类型检查与单元测试
node node_modules/typescript/bin/tsc --noEmit
node node_modules/vitest/vitest.mjs run

# 后端测试
.\.venv\Scripts\python.exe -m pytest backend/tests -q

# 构建 Windows 安装包（输出到 release/）
node scripts/package.mjs

# 生成基础离线资源包
.\.venv\Scripts\python.exe scripts/resources-pack.py
```

### 技术栈与目录

桌面端使用 Electron、React、TypeScript 和 Vite；本地后端使用 FastAPI、Demucs 4、PyTorch／torchaudio 2.7.1、Basic Pitch ONNX 与 FFmpeg。实时演奏通过 SpessaSynth 和 AudioWorklet 合成，不经过逐音符 Python 请求。鼓使用击打起点分析与节奏模板。

| 目录／文件 | 内容 |
| --- | --- |
| `src/` | 工作台界面、音频引擎和前端测试 |
| `desktop/` | Electron 主进程、受限 IPC、后端管理与卸载集成 |
| `backend/` | 本地 API、串行推理任务、转谱、编配、资源与工程管理 |
| `scripts/` | 初始化辅助、构建、资源打包与集成检查 |
| `src/types.ts`、`backend/models.py` | 共享数据契约 |
| `docs/COMMANDS.md` | 指令演奏规则 |

后端仅绑定本机随机端口，使用会话令牌；音符以秒记录，MIDI 导出按节拍映射转换。分离与转谱结果缓存，风格编配通过随机种子保持可重复。模型、运行环境、用户音频和大型构建产物不提交到 Git 历史。
